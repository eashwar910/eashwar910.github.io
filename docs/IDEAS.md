# Ideas (not built)

- **Landmark pairings with a reason.** Konark Sun Temple still suits the Odisha project, and a Moai suits "things carved over time" (Skills). Swap in `content/landmarks.ts` if a pairing should mean something.
- **Smarter hints.** Instead of a compass word, a faint arc along the globe's limb pointing at the nearest unopened landmark, or a slow auto-rotation toward it after 20 s.
- **A better marker for found vs not found.** A filled ring already marks opened ones. A tiny tick, or a slow glow only on unopened markers, would read faster.
- **Show all as a map-less index.** A top table of contents with the landmark name next to each section ("Colosseum, Rome: Lab") would keep the globe story alive in the plain page.
- **Spin momentum for auto-rotation** that continues from where the user let go, rather than restarting at a fixed speed.
- **Landmark photos** only if clearly free to use (Wikimedia Commons with attribution); none are used now.
